# 오디오

- `intro-silent-night.mp3`: 인트로 배경음악. 사용자가 제공한 "Silent Night" 피아노 커버 녹음의 앞 45초(1초 지점부터)를
  잘라 페이드 인/아웃, 음량 정규화(-20 LUFS), 96kbps로 인코딩했습니다.
  - ⚠️ 곡(고요한 밤, 1818)은 퍼블릭 도메인이지만, **이 녹음(연주)의 권리는 연주자에게 있습니다.**
    정식 출시 전에 연주자의 사용 허락 또는 상업적 사용이 가능한 라이선스를 확인해야 합니다.
- 별똥별 효과음은 파일 없이 Web Audio로 합성합니다 (`lib/intro-audio.ts`).
