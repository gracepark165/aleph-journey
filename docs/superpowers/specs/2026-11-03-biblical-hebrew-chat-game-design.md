# 성경 히브리어 대화 학습 게임 — 설계 문서

- 작성일: 2026-11-03
- 상태: 사용자 검토 대기
- 가칭: **"알레프 여정"** (정식 이름은 출시 전 결정, 기능 설계와 무관)

## 1. 목표와 대상

**사용자가 정한 것**
- 많은 사람이 쓰는 공개 서비스로 출시한다.
- 언어: **성경 히브리어**.
- 대상: **한국어 사용자**.
- 학습 방식: **혼합형** — 본문 읽기로 단어·문법을 배운 뒤, 그 장면을 롤플레이 미션으로 복습.
- 롤플레이 방식: **접근법 A — 시나리오 대본 + AI 채점**. 등장인물 대사는 전부 사람이 미리 쓰고 검수한 문장.
- 플랫폼: **웹앱(PWA) 먼저**.
- 기술: Next.js + Supabase + Claude API.

**가정 (사용자 확인 필요 시 수정)**
- 수준은 입문자(알파벳 모름)에서 시작해 점차 신학생 수준까지 확장.
- 1인 또는 소규모 팀 개발을 전제로 MVP 범위를 작게 잡는다.

**원칙**
- 특정 기존 앱(말해보카 등)의 이름·캐릭터·디자인을 차용하지 않는다. "대화형 미션으로 복습" 메커니즘만 참고한다.
- 히브리어 정확성이 최우선. AI는 대사를 생성하지 않고 채점·피드백만 한다.

**성공 기준 (MVP)**
- 입문자가 알파벳 유닛 → 창세기 유닛 1을 막힘 없이 완료할 수 있다.
- 모든 롤플레이 대본 분기가 끝까지 도달 가능하고, 모든 히브리어 단어가 사전에 존재한다(자동 검사 통과).
- AI 채점 장애 시에도 학습이 중단되지 않는다.

## 2. 학습 흐름과 콘텐츠 구조

```
코스 (예: 창세기 입문)
 └ 유닛 = 성경 장면 하나 (예: 우물가의 리브가, 창 24장 일부)
     ├ ① 본문 읽기    : 구절을 단어 단위로 탭 → 뜻·음역·원형·문법 카드
     ├ ② 연습 퀴즈    : 단어 뜻 고르기, 듣고 고르기, 어순 배열
     └ ③ 롤플레이 미션 : 장면 속 인물과 분기형 대본 대화
```

- **유닛 0 — 알파벳**: 자음 22자 + 모음 부호(니쿠드). 배치 테스트 통과 시 건너뛰기 가능.
- **MVP 콘텐츠**: 알파벳 유닛 + 창세기 유닛 5개.

### 롤플레이 미션
1. 인물이 히브리어 대사 제시. 한국어 해석·음역은 토글.
2. 응답 모드(난이도별):
   | 모드 | 입력 | 채점 |
   |---|---|---|
   | 쉬움 | 보기 3개 중 선택 | 규칙(정답 ID 비교) |
   | 보통 | 단어 블록 조립 | 규칙(정규화 후 순서 비교, 허용 정답 목록) |
   | 어려움 | 직접 타이핑 | AI(Haiku) 의도 채점 |
3. 분기는 대본에 정의된 대로만 진행. AI는 분기를 고르지 않는다(통과/불통과만 판정).

### 콘텐츠 제작
- 레슨·대본은 저장소 내 JSON 파일. 별도 관리자 화면은 MVP에서 만들지 않는다.
- 본문과 단어 정보는 공개 데이터에서 추출:
  - 본문: Westminster Leningrad Codex (퍼블릭 도메인)
  - 형태소/원형: Open Scriptures Hebrew Bible (OSHB, CC BY 4.0 — 앱 내 출처 표기 필수)
- 한국어 뜻·해설·대본 번역은 직접 작성.
- 발음 음성: 성경 히브리어 TTS 품질이 낮으므로 MVP는 핵심 단어·대사 직접 녹음 파일을 사용. 녹음이 없는 항목은 음성 버튼을 숨긴다.

## 3. 게임 요소

**MVP 포함**
- **XP**: 레슨 완료 시 지급. 롤플레이 미션 보너스, 무실수 보너스.
- **스트릭**: 하루 목표(기본 레슨 1개) 달성 시 연속일 +1. 기준 시간대 Asia/Seoul.
- **안식일 쉼표**: 주 1회 자동 지급(최대 보유 1개). 하루를 놓치면 자동 소모해 스트릭 보호.
- **성막 등불**: 롤플레이 미션 전용. 3개로 시작, 오답마다 1개 소등, 0개면 미션 재시작. 본문 읽기·퀴즈는 패널티 없음.
- **단어장 + 복습 큐**: 배운 단어 자동 수집. 틀린 단어는 간단한 간격 반복(1·3·7·14일)으로 재출제.
- **진도 지도**: 유닛을 성경 지리 위 여정 경로로 표시.

**MVP 제외**: 리그/랭킹, 친구, 상점, 배지, 결제.

**수익 모델(출시 후)**: 무료(알파벳 + 창세기 초반) / 구독(전체 코스, AI 타이핑 채점, 등불 무제한). MVP는 전부 무료로 열고 지표 확인.

## 4. 시스템 구조

```
[브라우저 PWA — Next.js]
   │  레슨 JSON·본문 데이터: 정적 파일, 서비스워커로 오프라인 캐시
   ├─▶ [Supabase]  인증(카카오·구글), 진도·XP·스트릭·단어장
   └─▶ [Next.js API /api/grade] ─▶ [Claude Haiku 5.5]  (타이핑 모드 전용)
```

### 모듈
| 모듈 | 책임 | 의존 |
|---|---|---|
| `content/` | 코스·유닛·레슨·대본 JSON, 단어 사전. 빌드 시 스키마 검증 | 없음 |
| `lib/script-engine` | 분기형 대본 진행 (순수 함수: `(대본, 현재노드, 응답결과) → 다음노드`) | content 타입 |
| `lib/grader` | 규칙 채점(보기·블록, 니쿠드 정규화 옵션), 타이핑 모드는 `/api/grade` 호출 | script-engine 타입 |
| `lib/progress` | XP·스트릭·등불·복습 큐 계산(순수 함수) + Supabase 저장 어댑터 | Supabase |
| `app/` | 화면: 홈 지도, 본문 읽기, 퀴즈, 롤플레이, 단어장, 로그인 | 위 모듈 |

### 데이터 모델 (Supabase)
- `profiles(user_id, display_name, daily_goal, rest_tokens, created_at)`
- `progress(user_id, lesson_id, completed_at, score, perfect)`
- `streaks(user_id, current, longest, last_active_date)` — 날짜는 Asia/Seoul 기준
- `vocab_reviews(user_id, lemma_id, next_review_date, interval_days, correct_count, wrong_count)`
- 모든 테이블 RLS: 본인 행만 읽기/쓰기.
- 콘텐츠는 DB에 넣지 않는다(파일로 버전 관리·검수).

### AI 채점 흐름 (어려움 모드)
1. 클라이언트 → `/api/grade`: `{lessonId, nodeId, userInput}`.
2. 서버가 대본에서 해당 노드의 `intent`(한국어 의도 설명)와 `acceptedAnswers`를 읽어 Haiku에 전달. 클라이언트가 보낸 정답 정보는 신뢰하지 않는다.
3. Haiku 응답(JSON 강제): `{pass: boolean, feedbackKo: string, closestAnswer: string}`.
4. 서버가 응답 형식 검증 후 반환. `closestAnswer`는 반드시 `acceptedAnswers` 중 하나여야 하며, 아니면 첫 번째 모범 답안으로 대체.

### 오류 처리
- AI 실패/5초 초과 → 해당 노드를 블록 조립 모드로 자동 전환 + "지금은 블록 모드로 진행해요" 안내.
- 남용 방지: 사용자별 하루 AI 채점 50회 제한(서버에서 카운트). 초과 시 블록 모드.
- 오프라인: 진도를 로컬(IndexedDB)에 큐잉, 재연결 시 동기화. 충돌 시 XP는 합산, 레슨 완료는 OR.
- 콘텐츠 로드 실패 → 재시도 버튼이 있는 오류 화면.

## 5. 테스트
- **단위(Vitest)**: script-engine 분기, grader 정규화·규칙, progress의 스트릭(자정·시간대 경계, 쉼표 소모)·등불·복습 간격.
- **콘텐츠 검사 스크립트**(CI 필수): 스키마 검증, 모든 분기 종료 도달 가능, 대본의 모든 히브리어 단어가 사전에 존재, 참조 ID 무결성.
- **API**: `/api/grade`는 Claude 클라이언트를 목으로 대체해 형식 검증·폴백 테스트.
- **E2E(Playwright)**: 로그인 → 레슨 1개 완료 → XP·스트릭 반영 확인; AI 실패 시 블록 모드 전환 확인.

## 6. 범위 밖 (MVP 이후)
- 네이티브 앱 래핑(Capacitor), 푸시 알림
- 결제·구독
- 관리자 콘텐츠 편집 화면
- 랭킹·친구·배지
- 영어 등 다국어 UI
